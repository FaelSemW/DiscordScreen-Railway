# Como contribuir

Abra uma issue descrevendo o problema, a versão do Windows, o navegador do
espectador e os passos para reproduzir. Não publique tokens, segredos do Discord
ou configurações pessoais. Para melhorias, envie um pull request com a motivação
e os testes relevantes. Execute `npm test` e `npm run build` antes de enviar.

O README descreve a compilação do aplicativo e do auxiliar de áudio.
Contribuições ao código deste projeto são disponibilizadas sob a licença MIT.
